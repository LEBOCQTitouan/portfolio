## Overview

End-to-end ownership of a live metrics dashboard: a Rust ingestion service
feeding a ClickHouse store, surfaced through a Next.js UI over WebSockets.

## Highlights

- Sub-second end-to-end latency from event to rendered chart.
- Backpressure handling so the UI degrades gracefully under spikes.
- Interface tuned for at-a-glance reading on large wall displays.
